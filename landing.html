في منصة واحدة

مُصمَّم للعرب، مُبني بأحدث التقنيات، يعمل على كل الأجهزة بسرعة وسلاسة.

غرف عامة وخاصة
أنشئ غرف مفتوحة للجميع أو خاصة بدعوة فقط. تحكم كامل في من ينضم وكيف تسير المحادثة.
متاح الآن
رسائل فورية Real-Time
تقنية Supabase Realtime تضمن وصول رسائلك فوراً بدون تأخير. تجربة محادثة طبيعية كاملة.
< 12ms تأخير
نظام الأصدقاء
أضف أصدقاء، تابع حالتهم، وراسلهم خاصةً. محادثات DM مباشرة مع كل صديق.
متاح الآن
مشاركة الصور
أرسل صوراً مباشرة في المحادثة. تُرفع على Supabase Storage بأمان وتُعرض فوراً للجميع.
مدعوم
ردود الأفعال
تفاعل مع الرسائل بـ emoji reactions، ورد على أي رسالة مباشرةً مع اقتباس المحتوى.
متاح الآن
أمان وخصوصية
تسجيل دخول آمن عبر Google أو البريد. Row Level Security على كل البيانات. بياناتك لك فقط.

ثلاث خطوات
وأنت داخل

بدون تعقيد. بدون إعداد طويل. فقط ادخل وابدأ.

01
سجّل دخولك
ادخل بحساب Google بضغطة واحدة، أو أنشئ حساباً بالبريد الإلكتروني خلال ثوانٍ.
02
اختر غرفة أو أنشئ
انضم لغرفة موجودة أو أنشئ غرفتك الخاصة — عامة مفتوحة أو خاصة بدعوة فقط.
03
تواصل فوراً
رسائل، صور، ردود أفعال، DMs. كل شيء يصل فورياً لجميع أعضاء الغرفة.
